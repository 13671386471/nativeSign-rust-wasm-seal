# 2026-10-21 — 选中红框改为"引擎层绘制"(方案B)

## 背景
上一轮"点击签章显示红框"用前端 DOM 覆盖层 `#sealSelectionBox` 实现。用户要求把功能封装在底层，
前端只负责数据传输/编排/事件触发，故改为**方案B：选中框由 Rust 渲染层画进 canvas 像素**，
彻底去掉 DOM 覆盖层。

## 实现（引擎层拥有全部逻辑）
- **状态**：`DocState` 新增 `selected_seal: Option<usize>`（存印章 id）；
  `DocState::default` / `DocumentEngine::load_file` 构造处初始化 `None`。
- **命中+选中**（engine.rs）：
  - 抽出 `compute_seal_hit(page, canvas_w, canvas_h, x, y) -> Option<(index, scale_x, scale_y)>`。
  - `hit_test_seal`（只查询，不改状态）改为复用它。
  - 新增 `select_seal_at(...) -> Option<String>`：命中则 `selected_seal=Some(id)` 并返回 JSON；未命中清空。
  - 新增 `clear_seal_selection()`；`delete_note` 删除的正是选中章时清空。
- **渲染**（render.rs）：
  - 新增自由函数 `draw_selection_rect(ctx,x,y,w,h)`：`save()`→`stroke_style "#FF0000"`→`line_width 2.0`→`stroke_rect`→`restore()`（空心直角实线）。
  - PDF `render_page_to_canvas`：印章叠加之后，若 `doc_state.selected_seal == seal.id` 且同页，
    按 `bmp_w/pdf_pw` 比例换算后画红框（在 putImageData 之后的像素层）。
  - OFD `render_ofd_canvas`：印章叠加之后，用与 `render_seal_ofd` 相同的坐标映射画红框。
- **wasm 导出**（lib.rs）：`select_seal_at(page,canvas_w,canvas_h,x,y)`（内部调用后 `refresh_render()` 重绘）、
  `clear_seal_selection()`（清空+重绘）。
- **桥接**（js/ofd_plugin.js）：新增 `SelectSealAt` / `ClearSealSelection` 并加入导出对象。
- **前端**（index.html）：
  - 删除 `#sealSelectionBox` 的 CSS、DOM 节点、`showSealSelectionBox`/`hideSealSelectionBox`。
  - 左键 click：命中 canvas 页就 `plugin.SelectSealAt(pageIdx, rect.width, rect.height, clickX, clickY)`；
    点空白/工具栏 `plugin.ClearSealSelection()`。
  - 右键 contextmenu：命中已有签章时也先 `SelectSealAt`（引擎画框）再弹菜单。
  - 前端只传 canvas CSS 尺寸 + 点击坐标，命中/选中/绘制全在引擎。

## 验证（无头 Chrome + CDP，像素级）
脚本 `test/verify-selection-canvas.mjs`：加载 test_labor_contract.pdf，用 `AddSeal` 放一枚 **1x1 透明章**
（使红框成为唯一红色来源），`SetPageMode` 后统计签章矩形区域红色像素：
- `#sealSelectionBox` DOM 元素：**已不存在**（domOverlayRemoved=true）。
- 点击前红色像素 **0**；点击章中心后 **739**（红框已画进 canvas）；点空白后 **0**（清除）。
- `SelectSealAt` 命中返回含 css_* 的 JSON。
截图 `test/out/selection-canvas.png`：可见红色空心矩形框直接绘制在页面画布内。

## 关键约定
- 选中框是"画布像素"，不是文档内容，保存/导出不会写入 PDF/OFD。
- `refresh_render()` 在每次选中变化时重绘全部页；canvas 按 `__pg_<container>_p<page>` id 复用，
  重绘后同一元素像素更新（故可在同一 canvas 上读 getImageData 验证）。
- 若后续要多选/拖动/缩放手柄，可在 `selected_seal` 基础上扩展（如 `selected_seals: Vec<usize>`）。
